Tutorial

ကျနော်တို့ Design Printing Service Company က Web Developer Team ကလူကြီးမင်းတို့ကိုယ်ပိုင် account လေးတွေနဲ့အသုံးပြုရာလွယ်ကူစေရန်အတွက် September လ 2022 မှာ address.dpsmap.com ရဲ့ account login system နဲ့ register system လေးကို မိတ်ဆက်ပေးလိုက်ပါပြီ။ လူကြီးမင်းတို့အခက်အခဲမရှိစေဖို့အတွက်လဲ လုပ်ဆောင်ရမယ့်အချက်အလက်တွေကိုလဲအောက်မှာဖော်ပြထားပါတယ်။

  1. DPS Home Page ထဲကမှ address ဆိုတဲ့ Button လေးကိုနှိပ်လိုက်ပါ
  2. account ဖွင့်ပြီးသား ရှိပါက username နှင့် password ကိုဖြည့်ပြီး login button ကို နှိပ်ပါ ။ account ဖွင့်ပြီးသားမရှိသေးပါက Register ပြုလုပ်ရပါမည်။
  3. Register ပြုလုပ်ရာတွင် အထူးသတိပြုရသည်မှာ
    • မိမိနာမည် First Name နှင့် Last Name ကို မှန်ကန်စွာရေးထည့်ပေးခြင်း ( ဥပမာ - First Name = Aung , Last Name = Oo)
    • Confirm Code ပြန်လည်ပို့ပေးမှာဖြစ်တဲ့အတွက်ကြောင့် မိမိ လက်ရှိ အသုံးပြုနေတဲ့ Email ကိုမှန်ကန်စွာဖြည့်ပေးဖို့တော့လိုပါတယ်နော်
    • လူကြီးမင်း သိလိုတဲ့မြေပုံအချက်အလက် ပြန်လည်ရှင်းပြပေးရာတွင် အဆင်ပြေရန်အတွက် လူကြီးမင်းတို့ ရဲ့ မှန်ကန်တဲ့ ဖုန်းနံပါတ်လေးတွေကိုလဲ ဖြည့်ပေးရပါမယ်ခင်ဗျာ့
    • Password အတွက် ဖြည့်သွင်းရာမှာလဲ Password Box နဲ့ Confirm Password Box ထဲက အချက်အလက်များတူညီနေမှသာ လူကြီးမင်းတို့ account ဖွင့်ရာမှာအဆင်ပြေမှာဖြစ်ပါတယ်နော်
    • Username မှာတော့ လူကြီးမင်းတို့ account မှာပေါ်အောင်ထည့်သွင်းရမည်ဖြစ်တာကြောင့် လူကြီးမင်းတို့ ကြိုက်နှစ်သက်ရာထည့်သွင်းအသုံးပြုနိုင်ပါတယ်။
    • Address Box နေရာမှာတော့ လူကြီးမင်းတို့ရဲ့ လိပ်စာလေးတော့ထည့်ပေးရပါမယ်ခင်ဗျာ့
    • ဒါလေးတွေ ထည့်ပြီးလို့စုံသွားတာနဲ့ Register Button လေးကိုနှိပ်ပြီး OTP Code လေးကို လူကြီးမင်းတို့ email , g mail ထဲပို့လာသည့် code 4 လုံးကို ဖြည့်ပြီး Confirm ကိုနှိပ်လိုက်ပါ။ login ဝင်တဲ့ page ကိုပြန်ရောက်တာနဲ့ လူကြီးမင်းတို့ထည့်ခဲ့တဲ့ username နဲ့ password ကိုပြန်လည်ဖြည့်ပြီး အသုံးပြုနိုင်ပါပြီ။
    • verification stage တွင် ချို့ယွင်းမှုတချို့ကြောင့် ထပ်မံလုပ်၍ မရတာမျိုးမဖြစ်စေရန် ကျနော်တို့ Developer Team မှ login ပြုလုပ်ရာတွင် verification stage ကိုထပ်မံပြုလုပ်နိုင်ရန် လုပ်ပေးထားပါတယ်။
